Dockline brings your GitHub repositories and your Hostinger websites and domains together in one Windows window.

## Install

1. Download **`Dockline-Setup-<version>.exe`** below (under *Assets*).
2. Run it and follow the installer. Java is included; nothing else needs to be installed.
3. Start Dockline from the Start menu and connect GitHub and Hostinger in **Settings**.

### "Windows protected your PC"

Dockline is not code-signed, so Windows SmartScreen may show a blue "Windows protected your PC" window the first time you run the installer. To continue:

1. Click **More info**.
2. Check that the app is `Dockline-Setup-<version>.exe`, then click **Run anyway**.

Only do this for an installer downloaded from this Releases page.

## Upgrading

Run the new installer over the old version. Your settings, manual links and tokens are kept: settings live in `%APPDATA%\Dockline` and tokens in Windows Credential Manager, and neither is removed by installing, upgrading or uninstalling.

There is no automatic update. To upgrade, download the newest installer from the [Releases page](https://github.com/DelucaGit/Dockline/releases).
